v0.1.0 改版 IBM Plex Mono 纸面 · 雾灰墨色 6 个页面

本轮调整 · 纸张感、雾灰配色、打字机动效、新 logo

范围改动
配色去掉品牌绿。纸面 --bg #E9E6DF / --surface #F7F5F0，墨色 --ink #2A2C2F，强调改为雾灰 --accent #5B636C / --accent-strong #3A4047。语义色降低彩度，像褪色印泥：警示 #8A6A30、危险 #93473A、信息 #56677A。分类色带与 treemap 改为雾灰 / 灰褐 / 灰紫 / 灰蓝的低彩度色阶。
纸张感页面底叠一层 SVG 噪点颗粒；面板是「纸片」：细描边 + 2px 硬投影，弹窗 4px；侧栏选中项像压在纸上的标签。
像素 × 字符圆角全部收回到 2px；复选框为方块、勾选填实心小方块；进度条与分析条切成 6px 格子，扫描进度按格跳动；磁盘环改为刻度表盘。区块标题前缀 #，导航选中 ▸，路径前缀 $ cd，命令前缀 $，提示前缀 >，空状态用 [ ] 括起；行分隔改为虚线；文字按钮改为点状下划线。
动效去掉淡入上移和所有缓动曲线。切换页面时，页面标题与各区块标题依次逐字打出（38ms/字，带方块光标）；区块按 3 档阶梯显影；按钮按下连同投影一起压下 1px。
Logopublic/icon.svg 是对折的「- -」：深雾灰底上一张印着「- -」的纸卡，右半边沿中线向后折过去一个角度——左半正对受光，右半透视变窄、背光，中线是折痕，纸卡留一道硬投影。

边框、圆角与高度层级

三级高度，像纸片叠在桌上：面用虚线分隔，面板是一张纸（细描边 + 2px 硬投影），弹窗是压在上面的厚纸（墨线 + 4px 硬投影）。

L1 · 工具条 / 次级面 — var(--surface-2) 底 + 虚线分隔，无投影。
L2 · 面板 / 卡片 — 1px var(--line-strong) + 2px 2px 0 硬投影。
L3 · 弹窗 — 1px var(--ink-2) + 4px 4px 0 硬投影，背后半透明墨色遮罩，不模糊。
--r-sm / --r / --r-lg / --r-pill: 2px;   /* 一律直角，2px 只为防锯齿 */
